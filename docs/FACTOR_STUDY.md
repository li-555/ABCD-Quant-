## 因子定义

| 候选 | 公式与用途 | 处理 |
|---|---|---|
| Relative Strength | 120 小时对 BTC 的超额对数收益，按自身波动率缩放并 tanh；补充已有横截面动量 | 验证 Sharpe 增量不足，关闭 |
| Mean Reversion | 价格对数偏离 24 小时均值的负向标准化值，tanh 压缩 | 验证收益变差，关闭 |
| Volume | 24 小时内 `sum(sign(log_return) * volume) / sum(volume)` | 保留 0.20 |
| Overnight/Intraday | 已完整结束 UTC 日的 00–08 与 08–24 收益差，20 日均值，波动率缩放 | 验证未改善，关闭 |
| Combined | 上述四项各 0.05，基线占 0.80 | 验证未改善，关闭 |

加密货币连续交易；时段因子是 UTC 时间段代理，不是股票开盘隔夜跳空。窗口、时段和权重没有根据留出数据调优。

保留配置：`S = 0.8 * S_v1 + 0.2 * Volume`；原来的 `S_slow` 方向门槛、趋势广度和仓位风控函数不变。缺失成交量时对应资产退回原分数；成交量不会前填/补零。所有可选权重为 0 时，原信号逐元素一致。

## 回测及接入边界

- 直接复用 `bot.strategy.signals`、`compute_target_weights` 和止损函数，使用现金/数量账本，卖出先于买入，无借贷。
- 仅用已收盘信号，以下一根 K 线开盘价加不利滑点成交；相邻 K 线开盘与前一根收盘的时间戳相同，交易日志另外记录 `fill_bar_close` 来区分。没有真实延迟/盘口回放。
- 每日 UTC 00:00 调仓，止损按 v1 的收盘价规则。没有用未来 high/low 给止损制造更优价格。期末按市值计价，没有强制清仓费用。
- 因子研究和纸面配置都关闭 `activity_enabled`。原系统的强制活跃交易、交易所精度/最低订单、订单超时与失败、Binance/Roostoo 价差未由这次历史测试证明有效。
- 回测按 14 日净值窗口计算回撤峰值；当前实时 scheduler 的峰值持久化逻辑仍偏向累计峰值，且同周期止损后重平衡的账户刷新存在原有差异。因此本报告是共享策略函数的研究回放，不是整个交易系统的逐订单等价验证。
- 当前固定币种清单存在幸存者/选样偏差。留出期改善幅度不大，未做统计显著性或多重检验校正；不构成未来收益保证。

## 如何运行

在仓库根目录：

```bash
python -m research.download_factor_data --output cache/factor_history
python -m research.factor_ablation --data cache/factor_history --output outputs/factor_study
python -m pytest tests -q
```

纸面运行：设置环境变量 `LIVE=0` 后运行：

```bash
python -m bot.main --config bot/config/volume_research.yaml --once
```

配置使用独立日志和状态路径。新 OHLCV 缓存会增量刷新，剔除未收盘 K 线；最新收盘价不完整时跳过周期。其他被淘汰因子仅保留在研究接口中，部署配置不启用。

## 后续回撤研究

### 回撤增加的原因

原策略最大回撤发生于 2026-01-06 14:30 至 03-23 07:30 UTC；Volume 最大回撤发生于 05-26 14:30 至 06-25 14:00 UTC。两者最大回撤不在同一区间，不能直接将差值全部归因到某个币种。

对齐到 Volume 的回撤区间，原策略亏损 16.95%、Volume 亏损 17.33%。按各自区间起点净值归一化，SOL 额外拖累约 0.61 个百分点、WLD 约 0.34 个百分点，部分被 UNI、ETH 的改善抵消。Volume 该区间最大的绝对亏损来自 WLD、NEAR、SOL。全期平均总仓位原策略 33.45%、Volume 33.26%，因此证据指向持仓组成与进出时机变化，而不是平均总仓位整体上升。

### 8 种风控调整均未通过筛选

事先固定候选和筛选条件，比较降低 Volume 权重、降低总/单币仓位上限、降低波动目标、增强回撤缩仓、收紧止损等 8 个候选。要求在 2024、2025 年、正常及双倍成本四种情况下都满足：相对 Volume 回撤至少下降 1 个百分点、不超过原策略回撤、保留至少 85% 的正收益、Sharpe 降幅不超过 0.1。

没有候选全部通过，未采用这些参数调整。例如 2025 年总仓位上限改为 60% 后，收益降至 16.52%、回撤反升至 26.13%。风控参数会改变后续交易路径，收紧参数不保证回撤一定下降。

### 可选现金预留方案

总初始权益 100,000 中固定预留 15,000，策略使用 85,000；保留 Volume 权重 0.20 和原交易规则。预留金额固定，不每日按净值再平衡，也不计利息。这是减少风险资金投入，不是新增因子的超额收益。

以下各时期独立起算，使用同一正常成本假设，收益未年化：

| 时期 | 原策略收益 / 最大回撤 | Volume 收益 / 最大回撤 | Volume + 现金预留收益 / 最大回撤 |
|---|---:|---:|---:|
| 2024 | 57.80% / 19.76% | 54.28% / 17.32% | 46.14% / 15.33% |
| 2025 | 21.78% / 24.74% | 28.80% / 22.63% | 24.48% / 19.59% |
| 2026 年 1–8 月 | 10.55% / 16.96% | 13.15% / 17.33% | **11.18% / 15.05%** |
| 2026-09-01 至 09-29（28 天） | 23.15% / 6.16% | 22.59% / 6.44% | 19.20% / 5.55% |

双倍成本下，2026 年 1–8 月现金预留配置收益 1.97%、最大回撤 16.70%；原策略为 0.14%、20.94%，Volume 为 2.32%、19.38%。现金预留降低了回撤，也牺牲了部分收益；它并非每个时期都优于原策略。

现金预留情景在上述 8 项实验失败后加入，未搜索预留比例，也没有宣称通过上述全部参数筛选门槛。**2024 至 2026 年 8 月已被观察过，后续比较是回顾性诊断，不能再次称为新的留出验证。** 9 月只有 28 天，不能证明长期稳健。

现金预留的现金/数量账本已检查逐点满足 `总净值 = 0.85 × 原 Volume 净值 + 15,000`，实际交易数量及费用同步缩放。新增测试覆盖 scheduler 使用 85,000 策略权益、报告 100,000 总权益的集成行为。

配置文件为 `bot/config/volume_cash85_research.yaml`。纸面运行前设 `LIVE=0`，并使用独立状态和日志；切换配置不能复用旧峰值记录。预留属于策略核算规则，不是托管隔离，不能保证未来最大回撤小于 15%。本地回放和实时执行差异仍适用上文列出的限制。
